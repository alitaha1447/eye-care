# Child Eye Care & Squint Clinic

Responsive React + Tailwind static website recreated from the provided visual reference.

## Pages
- Home
- About Us
- Child Squint
- Adult Squint
- Techniques
- Gallery
- FAQ
- Contact Us

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Replace dummy images

All image areas are intentionally rendered as dummy placeholders. Replace them with real images inside `public/images/` and pass paths such as:

```jsx
<DummyImage src="/images/doctor.jpg" alt="Doctor" />
```

## Design reference

The implementation follows the supplied reference image:
- Deep navy #092C61
- Medical green #3B8D62
- Pale blue section backgrounds
- Rounded cards
- Compact medical-clinic typography
- Desktop two/three-column layouts
- Mobile navigation and stacked sections
- Responsive forms and cards
